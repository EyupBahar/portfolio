## How I work

1. Analysis: Clarify the goal, the content and the existing data. Whatever is missing gets flagged, not invented.
2. Implementation: Small components, content from a single source, strict TypeScript. Astro for websites; Next.js, Angular or React for applications.
3. Review: Build, types, security headers, performance budget and tests run automatically before every release, plus a security audit with a dedicated tool.
4. Delivery: Deployment on Vercel, documentation for the handover.
